# SAFARI BOSS FIGHT

Законченная небольшая браузерная битва на русском языке. Три концовки, семь атак, три уровня интенсивности. Публикация не выполнялась.

## Запуск

Самый простой вариант — открыть `SAFARI-BOSS-FIGHT.html` из папки release в современном браузере. Все ресурсы встроены, интернет не нужен. На ПК подходят Chrome, Firefox, Safari и Edge. На мобильном устройстве нужен именно браузер, а не предпросмотр файла в мессенджере. Некоторые версии iOS и файловые просмотрщики не запускают локальные HTML со скриптами; в таком случае используйте ПК или последующую публикацию на HTTPS-хостинге.

Для разработки: из папки source запустите `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Ни npm, ни сборщик для работы не нужны. Содержимое source готово для статического хостинга; index.html — входная страница. Исходники нельзя публиковать автоматически без разрешения владельца.

## Управление

- Телефон: горизонтально; левый стик — движение; РЫВОК — короткая неуязвимость, откат 2,8 секунды.
- ПК: WASD или стрелки; пробел — рывок; Enter — продолжение диалога / удар; 1–4 — пункты основного меню; Esc — пауза.
- FIGHT: остановите метку в центре. Урон 8–28.
- ACT: разные действия повышают доверие. Повторные действия доверия не дают.
- ITEM: два шоколада (+20), один чай (+30), одно пирожное (+15 и защита от трёх ударов).
- MERCY: четыре уникальных взаимодействия и завершённый «Последний снимок» открывают мирный исход.
- В паузе есть раздельная громкость музыки и эффектов. Звук включается только после нажатия «Начать».
- Потеря фокуса автоматически ставит игру на паузу. Лучший результат сохраняется локально, если браузер разрешает localStorage.

## Концовки (спойлеры)

1. Боевая: снизить 180 HP Сафари до нуля. Идеальный удар побеждает за семь атак игрока.
2. Мирная: доверие не менее четырёх, пережить последний снимок, выбрать MERCY.
3. Секретная: спросить о камере, позировать, достичь последнего снимка. Во время экспозиции оставаться неподвижным внутри рамки не менее 0,48 секунды. Затем предложить общее фото в ACT либо выбрать MERCY.

Урон по душе — 6, с защитой — 3. После урона даётся 1,05 секунды неуязвимости. Защитный рывок не бесконечен. Все полосатые/рамочные опасности имеют задержку. Бледные фоновые листья не наносят урон; рыжие листья внутри арены — снаряды.

## Файлы и ресурсы

- `game/engine.js` — независимые правила и состояния боя.
- `game/app.js` — Canvas, DOM-интерфейс, ввод, звук и хранение результатов.
- `game/style.css` — масштабируемый интерфейс 960 × 540, сенсорные элементы.
- `assets` — все семь исходных ресурсов пользователя плюс подготовленные атласы, постер и оригинальный пиксельный шрифт интерфейса.
- `prepare_assets.py` — нарезка с общей точкой опоры; сохранение пропорций; ближайшая интерполяция; мягкая осенняя замена голубых вспышек.
- `make_font.py` — оригинальный пиксельный алфавит интерфейса.
- `build.py` — сборка автономного HTML со встроенными ресурсами.
- `ASSETS.md` — перечень ресурсов и их применение.

Подготовка ресурсов требует Python, Pillow, NumPy, SciPy и fontTools. Для обычного запуска они не нужны. Для пересборки автономного HTML нужен только Python: `python3 build.py`.

## Проверки и ограничения

`node game/test.cjs` — 11 наборов проверок правил: три концовки, здоровье, поражение, предметы, повторные ACT, точность, рывок, предупреждения, переходы всех семи атак во всех трёх фазах.

`node game/smoke.cjs` — проверка привязок UI и вызовов отрисовки через имитацию DOM: меню, удар, семь атак, пауза, итог, повторный запуск. Это НЕ полноценный браузерный тест. В проверках окончания атак временно включается неуязвимость, чтобы отдельно проверить переходы состояний; это не доказательство баланса живого прохождения.

PNG-атласы осмотрены, все MP3 и MP4 декодированы FFmpeg без ошибок. HTML не использует внешние библиотеки и сетевые запросы. Реальный браузер и Android/iOS в этой среде не проверялись. Перед публикацией нужен игровой прогон на телефоне: звук, мультитач, читаемость и баланс. Абсолютное отсутствие багов не заявляется.

Технический выбор: браузерная 2D-игра в эстетике 16-битных RPG, не ROM для 16-битной консоли. Задний план — предоставленная видеопетля; спрайты рисуются без сглаживания. Диалоги набраны читаемым моноширинным шрифтом, заголовки и кнопки — оригинальным пиксельным.

## Исправление мобильного экрана и звука — версия 1.1

Сцена размещена в фиксированном контейнере без переполнения. Масштаб и центр вычисляются по Visual Viewport с учётом появления панелей браузера, поворота и полноэкранного режима.

Музыка portrait_of_a_rival и два исходных эффекта теперь декодируются в Web Audio после жеста пользователя. Только один музыкальный источник; пауза сохраняет позицию, новая игра начинает трек сначала. Для несовместимых браузеров предусмотрен HTML Audio. Кнопка ♪ повторно разрешает звук, настройки показывают статус воспроизведения.

`node game/mobile-audio-test.cjs` проверяет геометрию шести размеров окна, видимость нижнего меню, единственный музыкальный цикл, громкость, эффекты, паузу и позднюю загрузку. Это проверки с имитацией аудиосреды, не прослушивание на устройстве. Реальный телефон и браузер в этом обновлении не тестировались.
